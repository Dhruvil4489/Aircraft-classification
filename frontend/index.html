Automated Aircraft Structural Damage Inspection

Automate the classification of exterior aircraft surface damage into dent or crack categories using a frozen VGG16 backbone with custom dense classification head, paired with HuggingFace BLIP for prompt-conditioned natural language damage descriptions.

🔍

Module A: VGG16 Classifier

ImageNet-pretrained VGG16 feature extractor frozen at all convolutional layers. Custom dual-dense binary head (512-ReLU, Dropout 0.3, 512-ReLU, Dropout 0.3, Sigmoid). Outputs calibrated posterior probabilities P(dent) and P(crack).

Input: 224×224 RGB Rescale: 1./255
📝

Module B: BLIP Vision-Language

Conditional generation with Salesforce/blip-image-captioning-base. Generates natural descriptions ("This is a picture of") and detailed prompt-conditioned summaries ("This is a detailed photo showing"). Wrapped in custom Keras layer.

PyTorch 2.2 CPU Concurrency Lock: 1
🛡️

Technical Architecture & Known Limitations

Comprehensive disclosure of engineering design decisions, framework boundaries, and operational constraints.

Framework Boundary Isolation

The project cleanly separates TensorFlow/Keras (for the VGG16 binary classifier) and PyTorch/HuggingFace Transformers (for BLIP). No internal framework tensor objects cross process or thread boundaries; all communication utilizes file paths, PIL images, or standard strings.

Custom Keras Layer Constraints

BlipCaptionSummaryLayer wraps PyTorch model execution inside a tf.py_function as an academic demonstration. Consequently, this layer is non-trainable, non-differentiable, and cannot be serialized into a TensorFlow SavedModel or graph. It is maintained strictly as an isolated helper.

Aviation Safety Disclaimer

This system was developed as an educational and research demonstrator using a small publicly available dataset. It is not certified by the FAA, EASA, or any aviation authority for airworthiness determination, structural integrity evaluation, or maintenance sign-off.

Caption & Summary Limitations

The BLIP model was trained on general web image-caption datasets. While it recognizes aircraft fuselages, engines, and surfaces, its generated text may hallucinate details or miss subtle microscopic fatigue cracks. "Summary" is conditioned solely via a longer prompt string, not a specialized aviation summarizer.
